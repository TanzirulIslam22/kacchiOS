# Video

`Demo_Video.mp4` must be recorded by the team (screen capture while the
OS runs in QEMU) — this repository deliberately contains **no fake or
empty video file**.

Until the video is recorded, follow `Demo_Script.md` in this folder: it
lists the exact commands to type and the exact output to expect for
every checklist item, so the demo can be reproduced (or recorded)
step by step.
